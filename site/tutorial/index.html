Tutorial · six steps, about five minutes

From a question to a merged dataset, without opening a codebook

Search every variable in the studies, see where a topic was measured, pick what you need and download a small R or Python project that builds your dataset from your own copy of the data. Every panel below is a working copy of the builder: try it as you read.

    Step 01 · Search

    Search names and labels

    Pick a cohort at the top of the builder, then type in the search bar. It matches variable names and labels as you type, across every sweep and file.

    • Type pregnancy, then habits, in the panel.
    • Press ▸ on a row to open it: its value labels, which codes count as missing, and its topics.
    • The coloured stripe on each name is its topic domain. The Measurement level menu narrows to nominal, ordinal or scale.
    –
      Step 02 · Explore

      See what was measured, and when

      Above the list, the builder charts the study. The first row counts the matching variables in each sweep; under Topics, each topic gets a row, one cell per sweep. Click a sweep bar or a topic to filter the list to it.

      • Click a topic name in the panel: the bars above it show that topic alone.
      • Within each topic shades every row against its own busiest sweep, so you can see when a topic was asked, even a rare one.
      • Across topics puts every cell on one scale, so you can see which topics the study asks most about.

        Step 03 · Select

        Build your selection

        Click a row to add it; click again to take it out. Selected rows turn green and gather in the panel beside the list, grouped by sweep or by file. The selection is kept in your browser, per cohort, so it is still there next time.

        • Click one row, then hold Shift and click another to select everything between them.
        • Select all takes every row the search matches.
        • The person identifier is always included, so the files can be merged.

            Step 04 · Download

            Download a project, not the data

            Review & download shows what you picked and asks how you want it. You get a zip of code: it reads only the files your variables are in, keeps only those columns, and joins the sweeps on the person identifier.

            • Choose R, Python or both, and the format to write.
            • Missing codes such as -9 Refused can become NA, or be kept as they are.
            • The site never holds study data: you bring your own copy, from the UK Data Service.

        Step 05 · Run
        
            Point it at your data and run

          path in the config file), and run one command. It writes your merged dataset to
          output/, with a README listing every variable and where it came from.

        Step 06 · Topics
        
            Where the topics come from
            
        
            Topics use the CLOSER taxonomy: the domains and topics of
          CLOSER Discovery, the search platform for
          UK longitudinal studies, with a few added for themes it lacks, such as Covid-19. Using one vocabulary means a
          topic means the same thing in every cohort.
            
        
            The tags are classified by a large language model (LLM): it reads each variable and
          gives it one or more topics, each with a confidence. In the builder,
          Topic tags ≥ sets how sure a tag must be before it is shown, counted
          and used in the filter. Try it on the right.

                Tagged with the Topic Tagger
                
          
                Every variable was tagged by our Topic Tagger, an open-source tool in this
            repository. It sends each variable's name, label and values to a large language model,
            which classifies it into CLOSER topics and says how confident it is. You can run it
            on any study.
