Tutorial · five steps

From thousands of variables to one tidy file, without writing the merge yourself.

Search the variables of UK cohort studies, pick the ones you need, and download a ready-to-run R or Python project that merges them from your own copy of the data, one row per participant. Everything below works: try it as you read.

    The site and the download contain no study data, only the published data dictionaries. You get the data itself from the UK Data Service.

    Step 1

    Choose a cohort and search

    Pick a study from the Cohort menu, then type any part of a variable’s name or label. Results update as you type.

    • Narrow it down by sweep, file, measurement level or topic.
    • Open a variable with ▸ to see its value labels, missing codes and topics.
    • Page through long results 200 at a time.

        Step 5

        Add your data and run it

        Get the data files from the UK Data Service. Unzip the project, put the files its README lists into data/ (.tab, .csv, .dta or .sav, in any subfolder) and run the script.

        my-project/
├── README.md        lists the files you need
├── data/            put them here
├── R/merge.R
└── python/merge.py

        $ Rscript R/merge.R

        → one file, one row per participant

        Topics

        One shared vocabulary across every cohort

        Every variable is tagged with topics from the CLOSER Discovery topic vocabulary: the two-level scheme CLOSER uses to index the questions and variables of UK longitudinal studies, built from MeSH and ELSST terms. Broad domains hold specific topics, so the same subject is found the same way in every study. We added a handful of topics where the vocabulary had no fit, such as Covid-19, bullying and survey weights.

        CLOSER Discovery The CLOSER resource profile (IJE)

            Tagged with our own tool

            Topic Tagger

            All the topics on this site were assigned by Topic Tagger, a standalone Python tool in this project. It reads a cohort’s data dictionary, tags each variable against a topic scheme like this one, saves as it goes and writes a report to review. It works for any cohort, not only these.

            Topic Tagger on GitHub

            Topics are a way in, not a verdict. They are machine-made, so a variable can be missed or tagged loosely: search by name and label too, and check anything you rely on against the study’s documentation.
